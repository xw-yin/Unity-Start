# 角色动作与服装适配

把表演、接触和模型变形作为同一个镜头来制作。编译通过、骨骼角度有限、若干帧相交为零，都不能证明动作自然。此 skill 是制作与审阅方法，不是专业动画师水平的保证。

## 起步

1. 读取项目约束、角色源数据、当前镜头和已有证据，保存可恢复的基线。保持源模型、工作副本和导入资产可区分。
2. 写一句镜头意图，例如“下班后松一口气，坐稳并慢慢脱靴”。确定角色性格、镜头、动作范围和目标设备。把“可爱”落实为姿态、视线和节奏，不能用统一摆手循环代替表演。
3. 按 [公开案例研究](references/source-study.md) 的记录格式选择参考。分清实际看过的画面、读过的作者说明和未能访问的内容；不得声称看过打不开的视频。
4. 一次先做一个角色、一段有明确问题的动作。已有用户授权时自主完成可逆的制作与审阅；本 skill 不额外要求审批。

## 制作顺序

### 1. 参考和动作设计

阅读 [动作设计](references/animation.md)。先完成动作节拍表、关键姿态草图、接触关系和鞋服可操作性分析。

- 参考必须匹配问题：步行看步行，抓握看抓握；搬重物的课程只能提供受力分析方法，不能直接当脱靴动作。
- 优秀动画用于研究设计与节奏；匹配服装的真实操作用于确认手如何用力、鞋如何松开。没有匹配参考时标为待验证，不用经验猜想宣称机制正确。
- 先用简单角色或关闭布料的工作副本做 stepped blocking。关键姿态和必要过渡姿态都要设计，不能直接对起止姿态做 SmoothStep。
- 审阅剪影、动作意图、承重和可达性后再转连续曲线。失败则退回设计层；不通过叠加呼吸、抖动或摆臂掩盖基础问题。

### 2. 模型、骨架和鞋服

阅读 [模型与接触](references/model-and-fit.md)。按外观来源核对身体、内外衣、腿、袜、鞋及材质；检查完整绑定矩阵、实际蒙皮和姿态变形。

- 用户要求保留原版时，记录每块源网格、外观和改动。原版缺失的隐藏部位只能说明缺失，不能把程序生成的部分称为原版。
- 先校正绑定、权重、关节体积和鞋腔容纳关系，再制作局部 corrective shapes。不要用全局缩小脚、把靴子整体绑脚骨或方盒裁切代替适配。
- 长裙、短靴、长靴、高跟鞋和露趾鞋分别设计接触与操作。先确定闭合结构能否解开，再决定脚退出路线。
- 角色控制骨架可重新搭建；变形骨架、源几何和导出关系必须可追溯。Blender 原生约束、驱动器与布料不会自动在 Unity 中运行；明确烘焙和运行时实现边界。

### 3. 曲线与次级运动

先稳定脚和抓握等主要接触，再调整骨盆、胸、肩、肘、腕、指的先后与弧线。放慢看接触，正常速度看节奏与意图。避免机械地给所有部位同一个起止时间。

身体与服装初始状态没有严重穿插后，再细化布料。固定、受手控制和自由垂落区域分别处理。折痕应从抓点、弯折和重力产生；规则正弦波仅能作为临时试验，不能当成已完成的布料表现。

### 4. 目标引擎验收

阅读 [回放与证据](references/review.md)。在 Unity 的实际导入结果中连续运行并保存证据；无法回放则明确留下未验证项。

交付必须分别报告：

- **表演**：正常速度下意图、节奏、手势和结束姿态是否成立。
- **形体与接触**：相关视角下抓握、承重、腿袜鞋完整性及穿插结果。
- **技术**：导入、编译、约束顺序、时序、回放及目标设备表现。

任何明显视觉问题都不能被技术通过抵消。不要把稀疏截图拼成“流畅动画”；不要把遮罩后的相交结果称为几何无穿插。无法判断时写“待验证”，给出缺失的证据。

## 可复用工具与输出

`scripts/contact_sheet.py` 将显式列出的本地帧整理成带角色、帧号、视角的对照板；不修改输入图片，不插帧，不评分。需要 Python 与 Pillow。输入清单及命令见 [回放与证据](references/review.md)。

每次输出一份镜头记录：意图、参考与访问状态、动作节拍、源模型清单、观察到的失败点、修改范围、实测证据、剩余未验证项。只把已看见且有依据的改进写成完成。
