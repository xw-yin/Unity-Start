## 学习结论

1. **表演从意图和姿态开始。** 《Spring》作者设定图同时明确服装外形与内部结构、正侧视图和表演用途。同一个 rig 的待机姿态可以通过肩、躯干、视线与手形传达不同性格。先为每个角色设计生活姿态。[Spring 原作者稿](https://www.davidrevoy.com/article712/spring-open-movie-character-design-and-concept-art)、[待机姿态案例](https://www.animationmentor.com/blog/10-advanced-acting-performance-tips-for-animators/)。
2. **从 A 到 B 的原因必须设计。** 推拉教学先分析参考、画草图、做阶梯关键姿态，再添加 breakdown，之后细化曲线。适用到这里是先画清抓稳、松跟、退出与释放；箱子推拉本身不是脱靴范本。[制作流程](https://www.animationmentor.com/blog/tutorial-animating-pushing-and-pulling-motions/)。
3. **手部需要整条身体链。** 肩、肘、掌、拇指与其余手指一起服务意图。自由摆动与接触锁定的任务不同。步行还需要承重、胸肩反向配合和停步过渡。[手部教学](https://www.animationmentor.com/blog/tutorial-how-to-animate-hand-gestures/)、[步行教学](https://www.animationmentor.com/blog/tutorial-animating-human-walk-cycle/)。
4. **布料问题可能从身体开始。** 《包宝宝》制作先处理身体自相交，再生成布料碰撞输入。先修身体、衣料层和鞋腔空间，再做柔软与折痕。[作者上传的论文](https://www.researchgate.net/publication/326908946_Clean_cloth_inputs_removing_character_self-intersections_with_volume_simulation)。
5. **正常速度回放是独立验收。** 关键帧和距离/相交测试不覆盖节奏、停顿、受力与收势。表演、形体接触、技术三个结论分别报告。

实际观察了 Spring 设定图和两种待机姿态静图；读取了上述教学文字及 Bao 论文文本。嵌入视频访问失败，部分 Blender Studio 页只有索引；没有声称看过它们的完整视频或源 rig。访问状态见 skill 的 `references/source-study.md`。

代码佐证与画面观察分开：

- `HomecomingBootSnapshot.UpdateShape` 使用高度包络、线性混合、缩短和正弦波；这些计算不会自动产生受力抓点附近的压瘪和合理截面，需以可观察的关键形状对照。
- `HomecomingMotion.ApplyCutePose` 叠加骨盆、脊柱、头的周期微动。缺乏意图的末姿态不能靠微动补足表演。
- `BootExtractionReview.Capture` 只在离散帧导出几何与画面。遮罩后的表面结果与抽脚全程几何适配不同。

## 首个制作练习：叶奈法左靴关键姿态

意图：“坐稳后专心松开软靴，抽出脚，放稳，缓一下。”使用现有成人角色及源衣服，不新造腿袜、不改其他角色。先验证几何连续性，然后在 Blender 工作副本制作下列姿态。暂不套入既有秒数，不复制整体左右动作。

| 姿态 | 身体和视线 | 接触任务 | 前提 |
|---|---|---|---|
| 坐稳/准备 | 座面与另一脚承重，看靴子 | 操作手接近，自由手任务明确 | 身体与服装初始无严重穿插 |
| 抓稳 | 肩与上身小幅靠近，肘不突兀外撑 | 拇指与手指夹住受力部位 | 靴口/闭合结构可松开，匹配参考待补 |
| 松跟 | 保持支撑，阻力与短停顿 | 手持续接触，脚跟相对后跟移动 | 足跟路线不穿硬后跟，袜腿连续 |
| 抽脚中段 | 膝、踝与退出方向协调 | 手抓点稳定，靴筒局部收缩 | 脚仍在鞋头时不用完全空靴形状；绷脚时机需参考 |
| 脚尖离开 | 收力，保持持物重量感 | 转为完整手持空靴 | 脚尖实际越过鞋头后切换 |
| 放靴/脚落地 | 脚跟、前掌支撑，身体回稳 | 靴到地面再松指，手随后离开 | 足底袜脚完整，空靴支撑与软塌合理 |
| 放松 | 完成任务后抬视线，肩放松 | 空手自然停留，剪影清晰 | 主视角与侧面成立，不用周期摇摆代替放松 |

这是可执行的 blocking 候选设计，并非已烘焙的新动画。软靴真实脱卸参考、关遮罩几何检查和正常速度回放是进入整套重制所缺的证据。先补上它们，不能重复数值通过就推广所有角色的做法。

## 普通步行补充研究（2026-10-12）

读过 Animation Mentor 的作者说明：[Tutorial: Animating a Basic Human Walk Cycle](https://www.animationmentor.com/blog/tutorial-animating-human-walk-cycle/)。重点是 contact/down/passing/up 的承重顺序、髋朝前腿转而胸肩反向、支撑脚平移与根节点速度配合，以及前臂和手腕的延续。该页嵌入视频访问被限流，没有声称看过视频。CAVE Academy 的步行页面只有搜索摘要可访问，未把它记为完整阅读。

本机游戏资源提供了可直接核对的普通女性步态：`animations/woman/movement/woman_movement.w2anims::locomotion_walk_cycle_slow_forward`，30 Hz、1 秒、31 样本（末样本为循环端点）。通过已安装 W3 工具解码。未选择醉酒、特殊角色或持伞步态。记录并转换完整髋、胸、肩、手、腿、脚运动；移除轨迹平移后保留侧向承重与垂直弧线。当前角色曾将原始 A 姿态转为 T 绑定并清除骨轴旋转，因此必须使用原始绑定、导入绑定、标准化绑定三者的矩阵关系，不能按骨骼名称直接复制局部四元数。

本研究的制作脚本是 `DCC/Blender/bake_native_walk.py`，工作副本是 `NativeWalkStudy.blend`；Unity 资源是独立的 `NativeWalkCycle.asset`。它们不修改原模型或原 `WalkCycle.asset`。首轮漏掉原骨轴转换的候选在 Unity 出现扭曲，已否决并修正，不能作为正确步态证据。
