# Blender 模型修正 — 2026-10-08

使用 Blender 5.2.2 LTS 和 BlenderMCP 导入、检查并修正七个角色。可编辑源文件为 `DCC/Blender/Characters.blend`，稀疏修正记录为 `DCC/Blender/refinements.json`。

## 修正范围

共修改 24 个网格的局部权重或法线。夏妮修正 296 组共享几何边的接缝权重，并重算此前补入、收合到袖内的 243 个原版上臂顶点的表面法线。叶奈法围巾修正 3 组接缝权重；特莉丝修正 2 组局部权重，其余角色整理近乎同向的接缝法线。未增加或删减顶点、三角面，也未替换腿、袜子、鞋子的原版形状。

九个导出姿势中的夏妮最大接缝张开从 4.863 毫米降至 0.001 毫米以下；这些数字仅衡量所修正的同位置接缝，不代表所有部件、所有姿势的碰撞保证。

## 导入与可维护性

Unity 导出真实模型和绑定矩阵，转换到 Blender 坐标后保留顶点编号。关键姿势使用每个骨骼的局部变换基，避免父骨骼尚未更新时直接赋全局矩阵导致错误变形。

稀疏修正只记录局部法线和四骨骼权重；Unity 应用前校验原始顶点、三角面及绑定数量的 SHA256。重新导入角色时会再次应用修正，并在之后生成脱下的鞋子，保留一致的表面法线。

Blender 文件保留九个姿势样本用于可视检查；完整脱靴过程、鞋袜独立性和实时布料在 Unity 验证。逐网格数据见本地 `Artifacts/BlenderOptimization/model-audit.json`。

## 验证结果

夏妮专项模型检查、七个角色各 961 帧的手部检查、鞋袜独立性检查和布料 60/20 FPS 稳定性检查通过。七个角色各 961 帧的实际 Play Mode 检查也通过，包括持鞋、完整袜子、骨骼连续性及重播。

日志为 `Artifacts/BlenderOptimization/unity-review.log`，明细为同目录的 `play-mode-results.csv`、`hand-metrics.csv` 和 `footwear-inventory.csv`。验证后同步 24 个网格到主项目，逐文件 SHA256 与验证项目一致，资源 GUID 保持原值。修改前网格备份在该目录的 `Before/`。
