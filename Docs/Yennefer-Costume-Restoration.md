# 叶奈法 DLC 服装材质对齐 · 2026-10-21

本轮继续处理叶奈法替代服装，目标是保留现有模型、UV、骨骼和动作，通过原资源补齐羽毛、围巾和皮革的材质层次。其他角色没有套用本轮参数。

## 原资源核对

- 后台 Blender 只读打开本机 `Yennefer-dlc-dress.blend`，审计全部 35 个材质及其原始参数；没有保存或重建源模型。
- 羽毛源材质为 `pbr_hair_moving`：各向异性为 0，透光量约 0.4，反光颜色为 42/97/95，原始漫反射是深蓝色羽毛，具有细羽枝 alpha。没有把它当成人物头发的高光来计算。
- 围巾源材质为 `pbr_std_tint_mask_det_pattern`：使用原有漫反射、法线 alpha 中的粗糙度、20 倍织物细节和 `pattern_array` 第 3 层花纹，花纹尺寸参数为 0.07。
- 四张基础漫反射/法线与项目里的 `Texture_12/13/24/25.png` 逐像素一致，因此复用现有资源。只增加两张粗糙度通道图、一张原版织纹法线、一张原版花纹，共四张运行时纹理。
- 每个源 DDS 的路径、尺寸、SHA256、准备资产路径及通道用途保存在 `Prepared/CostumeAppearance/source.json`。

[官方 Steam DLC 页面](https://store.steampowered.com/app/370002/)用于确认替代外观的身份；本轮未成功查看该页面的推广图，不将它列作已经完成的游戏实拍对照。材质判断主要依据本机原始资源、参数和 Unity 实际渲染。

## 修改

1. 羽毛使用独立于头发发丝高光的反射分支，恢复源颜色反光、粗糙度和薄片背光。主体使用 alpha 覆盖，低 alpha 羽枝使用共享原网格和骨骼的透明边缘层。
2. 围巾恢复原版花纹、织物细节和粗糙度。原法线 alpha 单独保留，避免 Unity 法线压缩后丢失粗糙度。细节振幅降为源参数的 0.35 倍，以适配 URP 的法线叠加；花纹的颜色和粗糙度混合也为明确的引擎适配，不宣称与 REDengine 相同。
3. 部分服装此前在粗糙度贴图之外，再将整体光泽乘以 0.4 或 0.6。本轮对非金属服装取消这层统一压低，并校正服装法线的绿色通道方向；保留银色饰件原来的光泽设置。
4. 材质通过导入清单中的槽位映射，不能拿 `Surface_14` 等 Unity 资产名和游戏材质名直接比较。羽毛/围巾的两个槽位匹配不完整时立即报错。
5. 透明边缘层重复应用时复用已有对象，避免每次重建头发对象导致无关预制体变化。新增羽毛层只引用现有网格，没有增加羽毛几何或改变轮廓。
6. 通用材质赋值不再向没有颜色属性的眼睑阴影着色器读取 `_Color`，消除该路径的材质属性错误。

`YenneferDLCImport` 现有外观流程会执行本轮服装适配，重新导入后仍能保留。运行游戏只依赖项目内准备好的资产，不需要读取本机游戏安装目录。

## 审阅与边界

证据目录：`Artifacts/AppearanceReview-20261021/`（不纳入 Git）。

- `baseline/` 与 `current/` 使用同一姿势、相机、房间光照和标准灯光；包含脸部、服装近景、全身前侧背视图。没有调整灯光来制造材质差异。
- 第一轮审阅发现新增材质未映射到实际槽位，已修复；后续透明层新增时的 Unity 对象空值处理错误也已修复。失败日志不是通过证据。
- 观察到羽毛从灰色硬片变为带细边的深蓝羽毛，围巾出现细花纹，皮革与缝线反光更清楚。标准侧光下围巾仍偏暗，肩部仍能看出源羽毛贴片结构。
- 技术检查通过：Unity 6000.6.3f1、强制 D3D11 的 Play Mode 实际渲染 930 帧，时间线按 30 Hz 求值，保留六张没有调用 BakeMesh 的运行截图；附加头发/羽毛层共享网格和骨骼，着色器无编译错误。49 个现有网格资产在主项目和验证副本中的 SHA256 都未改变。
- `runtime/`、`runtime.log` 保存运行证据，`geometry-baseline.json`、`applied-assets.json` 保存网格校验和应用清单。该回放是材质和蒙皮检查，没有给动画艺术质量评分。
- 源顶点色审计发现衣身 RGB 为白色，不据此臆造棕色染色；羽毛具有变化的顶点 alpha，其原游戏运动用途本轮未复现。
- 该轮只验证外观和材质绑定，不将截图或技术检查当作脱靴动作美感通过。原游戏完整的羽毛、布料着色及动态效果尚未完全复制，也未验证 iOS 真机性能。

## 复现

后台 Blender：`DCC/Blender/audit_yennefer_appearance.py --all --output <审计目录>`。源贴图转换：`python DCC/Blender/prepare_yennefer_costume.py --audit <审计目录>/source-materials.json`。

在 Unity 验证副本中，`Homecoming.Editor.YenneferAppearanceReview.CostumeIteration` 输出材质修改前后对照；`Homecoming.Editor.YenneferAppearanceRuntime.Run` 执行 Play Mode 渲染检查，使用 `-batchmode -force-d3d11`，不添加 `-quit` 或 `-nographics`。输出位于 `Artifacts/CostumeReview/`。运行器自行退出编辑器，不应在用户正在编辑的主工程中执行。
