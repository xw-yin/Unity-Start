# 叶奈法原版蕾丝延续 — 2026-10-08

原始 `stockings_01_wa__yennefer_d01.dds`（项目 `WitcherYenneferDLC/Prepared/Texture_04.png`）包含上沿窄花边及下方连续花卉蕾丝，不是上方花边、下方纯黑。游戏 DLC `body_05_wa__yennefer_Material6` 只建模露在靴外的 266 顶点、360 三角面；没有独立完整袜腿、袜脚。此前纯黑下半段是按当时用户要求制作的适配，不是原版贴图的下半段。

本次按用户选择将原版花卉纹样延续到完整袜腿、袜脚。上部原始 UV 和三角面保持；下部使用原版裸腿/脚表面和同一张蕾丝贴图，没有绘制新花纹。原始皮肤 UV 显式保存在第二套 UV，避免重建网格时保留下来的旧 UV 通道包含未初始化数据。

2026-10-09：完整花纹袜面只在该侧抽靴后渲染。穿靴时使用 DLC `body_05` 自带的露出腿面和原版花边，两者使用同套靴口遮盖靴内覆盖区。完整袜面来源属于另一套原版裸身资源，不能永久叠在 DLC 身体、靴子外面；原始足部仍完整保留，脱靴后的延续花纹仍属于项目适配。

下段花纹根据原始花边与皮肤 UV 的对应关系适配到原模型 UV 布局；袜口附近保留原生相位，再过渡到腿脚 UV，避免固定圆柱中轴造成脚背和小腿条纹拉伸。花卉区域在 V 方向镜像延续，避开原贴图顶部的窄花边重复到小腿。必要的 UV 接缝只复制原始顶点数据；每个三角面的原始位置和骨骼权重逐项保持。袜脚仍是原版腿脚表面的材质适配，不声称游戏已有完整独立蕾丝袜脚。

花纹空隙显示原始皮肤，只有原始 alpha 中的织纹染黑。当前全蕾丝样式直接采用原始 alpha；此前 10–30D 纯黑薄袜吸收参数不再决定花纹覆盖度。原版皮肤、轻微织纹法线和不透明深度合成保持，避免叠面排序问题。

配套原版 DLC 靴及穿脱检查见 [长靴说明](Yennefer-Original-Boots.md)。最新实际 Unity 图位于 `Artifacts/YenneferLaceBoots/675-front.png`，穿着图为 `240-front.png`；旧 `Artifacts/YenneferSheerHosiery/` 的纯黑预览是历史版本。Blender `DCC/Blender/Characters.blend` 已同步这版花纹和模型。
