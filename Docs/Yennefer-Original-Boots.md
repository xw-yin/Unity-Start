# 叶奈法 DLC 配套原靴及穿模修复

当前服装为 DLC4 `body_05`。之前选用了常服 `l_02_wa__yennefer` 靴，虽恢复其完整网格，仍与 DLC 服装的袜口和腿围不匹配；该选择已替换。

本次原靴来源为本地 `dlc/dlc4/data/characters/models/main_npc/yennefer/model/body_05_wa__yennefer.w2mesh`，读取 `F:/Unity/ExtractedModels/Yennefer/Yennefer-dlc-dress.blend`。其中材质 1 包含靴壳，材质 8 包含折边、绑带和装饰。脚本 `DCC/Blender/export_dlc_yennefer_boots.py` 按完整连通部件分离靴与护腕，不按高度裁掉靴子三角面；原始部件区间见 `DLCBoots/manifest.json`。

左右靴各 2057 顶点 / 3053 三角面，高度约 0.678m，原始五骨骼蒙皮、UV、法线及两组面保留。采用 DLC `body_05` 自身的皮革贴图与法线，URP 材质为适配，不声称复现完整 REDengine 材质图。原有鞋网格 GUID 保留，常服靴源文件留作历史来源。

穿模修正：

- 2026-10-09 修正穿着层：穿靴时改用同一个 `body_05` 的 Material7 露出腿面（左 232 / 右 219 顶点）和 Material6 花边（每侧 133 顶点），保留其原始位置、UV 和权重。完整裸身资源适配袜面不再在穿靴时常驻渲染；左右脚在各自抽靴时才启用完整袜腿、袜脚，原版穿着层同时关闭。
- 原版露出腿面也有延伸到靴内的覆盖区，按同套靴口的静止坐标遮挡该区，边界随蒙皮移动。原版花边使用原贴图 alpha 剪裁，且颜色、深度、阴影采用相同覆盖规则。该操作不删除源三角面，也不把腿永久缩细。
- 靴口识别改用所有材质面焊接后的边界连通环，避免把系带、装饰开口当成靴口。
- 仅穿着时通过 `BootFit` 局部形态把原始腿面和花边贴合靴内空间，最大横向调整约 26.5mm；原始中性顶点、原始裸足和三角面保持。袜与花边仍间隔约 1.5mm。脱靴时平滑恢复原始腿型；该贴合不改变脚部几何。
- 手持网格在脱离时烘焙实际蒙皮姿态，保持顶点连续；抽出后沿腿外侧携带，避免冻结的鞋头穿过正在回落的脚。空靴延迟到放置末段才恢复静止形态；当前形态在腕部目标计算前更新，用于地板约束。
- 抽脚期间继续使用当前手持网格的实际范围遮挡鞋内袜面，靴筒离脚后恢复完整花纹袜脚。

验证在独立 `StartMotionValidation` 编辑器进行。新增三角面相交审阅输出真实场景姿态和 Shader 遮挡条件，不再只检查鞋袜是否独立、是否消失。

- 此前适配袜面方案的 91 个时间采样、364 组表面检查曾通过，但仍未覆盖用户实际看到的穿着错误，因此不能作为当前问题已解决的证明。新版检查导出实际启用的 DLC 腿面 / 花边，而非已关闭的完整袜面；同时在 Play Mode 直接渲染 SkinnedMeshRenderer，额外保存 `*-gpu-front/side.png`，不以 BakeMesh 预览替代实际蒙皮路径。
- 左右穿着到手持网格的最大顶点误差约 0.000215 / 0.000179mm。
- 七角色各 961 帧实际 Play Mode 全流程通过，覆盖抓握、袜层保留、动作连续性和重播；叶奈法最大腕部目标误差约 0.531mm。
- 蕾丝 UV 接缝按每个三角面的源位置、源蒙皮权重检查，保持原始腿脚表面。

证据位于 `Artifacts/YenneferLaceBoots/`，包含 `intersections.json`、`intersections-final.log`、`continuous-results.csv`、`unity-final.log` 及正侧面截图。此结果覆盖列出的模型和采样状态，不代表所有未来动作、所有服装组合都无穿模。Blender 已同步配套靴、完整花纹及检查姿态。
