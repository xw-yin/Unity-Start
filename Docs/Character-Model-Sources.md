# 人物腿脚与鞋袜来源

当前七个人物的衣服、鞋和人物骨架均从本机《巫师 3》资源转换。女公爵为安娜·亨利叶塔，使用 `anna_henrietta_green` 绿色双层礼服。

游戏的着装模型通常没有鞋内完整的脚。当前使用游戏自带的通用女性腿脚网格 `characters/models/common/woman_average/body/model/ls_02_wa__body_barefoot.w2mesh` 补齐鞋内可见部分；并非声称每位人物着装资源都含有独立裸足版本。转换保留原始三角面、UV 和骨骼权重，只作骨架位置匹配和服装遮挡区域的原始三角面选择。当前人物不再使用 VRoid 腿脚，也不从鞋子形状生成脚。

原始袜子和裤腿保持在人物骨架上，独立于可脱下的鞋。例如女公爵的 `l_02_wa__anna_henrietta_Material2` 为保留的袜子表面，材质 0、1 才进入脱下的鞋。夏妮原始 `l_01_wa__shani` 也保留。统一模型中的鞋与裤腿按完整表面连接区域分类，避免按高度把裤腿切进鞋里。

每侧腿脚、连续丝袜、可脱鞋分别使用独立 Mesh 资源和独立 SkinnedMeshRenderer，并通过 CharacterRig 的 anatomicalLegs、hosiery、leftShoe/rightShoe 显式关联。连续袜层复制游戏腿脚的原始三角面、顶点和骨骼权重，覆盖脚趾、脚背、脚底至服装遮挡区；它是项目服装适配，并不是从游戏提取到的每位人物专用完整丝袜。袜层为不透明表面，里面的原始皮肤渲染器保留但关闭，避免重合面闪烁。脱鞋只关闭鞋子，腿脚和袜层始终保留。

穿靴时袜层使用 Stocking Coverage 材质遮挡鞋内表面，避免通用游戏脚趾露出较窄的角色靴壳。鞋子开始成为手持物时，立即取消对应袜层遮挡；不能继续用旋转后的鞋包围盒裁切露出的脚。袜面网格本身没有删除三角面。

叶奈法不再加载旧版 DLC_Stocking 圆筒形补袜网格，连续袜面使用无底色贴图、无法线花纹贴图的中性纯黑材质。其他角色原始袜子和裤腿表面仍保留。

爱丽丝和女公爵的长裙先由空闲手抓住前裙摆并提起，露出鞋，再由另一只手抓鞋口脱鞋；提裙手在放鞋期间继续保持裙摆。原始布料的自由度权重用于项目内的动态求解，裙摆有坐姿及提起姿态适配。

鞋型按鞋网格实际高度分为鞋（不超过 0.16m）、短靴（0.16–0.30m）和长靴（超过 0.30m）。短靴抓靴口，抽出距离为 0.22m，不采用长靴绷脚；长靴沿靴筒方向抽出 0.50m 并配合脚踝伸展。长裙角色保持提裙流程，具体抽鞋动作仍由鞋型决定。

编辑器菜单 Homecoming/审阅独立腿袜鞋 会输出 Artifacts/FootwearAudit/inventory.csv，检查独立网格、完整袜面与源腿脚一致、骨架一致、脱鞋后袜层保持显示、黑袜无花纹，以及先提裙再抓鞋。
