# 人物腿脚与鞋袜来源

当前七个人物的衣服、鞋和人物骨架均从本机《巫师 3》资源转换。女公爵为安娜·亨利叶塔，使用 `anna_henrietta_green` 绿色双层礼服。

游戏的着装模型通常没有鞋内完整的脚。当前使用游戏自带的通用女性腿脚网格 `characters/models/common/woman_average/body/model/ls_02_wa__body_barefoot.w2mesh` 补齐鞋内可见部分；并非声称每位人物着装资源都含有独立裸足版本。转换保留原始三角面、UV 和骨骼权重，只作骨架位置匹配和服装遮挡区域的原始三角面选择。当前人物不再使用 VRoid 腿脚，也不从鞋子形状生成脚。

原始袜子和裤腿保持在人物骨架上，独立于可脱下的鞋。例如女公爵的 `l_02_wa__anna_henrietta_Material2` 为保留的袜子表面，材质 0、1 才进入脱下的鞋。夏妮原始 `l_01_wa__shani` 也保留。统一模型中的鞋与裤腿按完整表面连接区域分类，避免按高度把裤腿切进鞋里。

为了保留当前场景的袜装设定，补齐部分使用深色袜面材质；这层材质是项目适配，不是声称游戏提供了对应人物完整脚部丝袜贴图。原始角色的袜子网格与贴图仍保留。

爱丽丝和女公爵的长裙先由空闲手抓住前裙摆并提起，露出鞋，再由另一只手抓鞋口脱鞋；提裙手在放鞋期间继续保持裙摆。原始布料的自由度权重用于项目内的动态求解，裙摆有坐姿及提起姿态适配。
