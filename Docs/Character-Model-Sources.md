# 人物腿脚与鞋袜来源

当前七个人物的衣服、鞋和人物骨架均从本机《巫师 3》资源转换。女公爵为安娜·亨利叶塔，使用 `anna_henrietta_green` 绿色双层礼服。

叶奈法现使用她专属的 `characters/models/main_npc/yennefer/model/twals_01_wa__body_notcensor.w2mesh` 原版腿与裸足网格，仅导出裙内以下的腿脚，不导出上半身。其解剖网格独立保留，纯黑丝袜层使用相同原始表面和权重；原服装残留的部分腿面与皮肤条带被移除，避免叠面露肤。其余角色的着装模型通常没有鞋内完整的脚，当前使用游戏自带的通用女性腿脚网格 `characters/models/common/woman_average/body/model/ls_02_wa__body_barefoot.w2mesh` 补齐鞋内可见部分；并非声称每位人物着装资源都含有独立裸足版本。转换保留原始三角面、UV 和骨骼权重，只作骨架位置匹配和服装遮挡区域的原始三角面选择。当前人物不再使用 VRoid 腿脚，也不从鞋子形状生成脚。

原始袜子和裤腿保持在人物骨架上，独立于可脱下的鞋。例如女公爵的 `l_02_wa__anna_henrietta_Material2` 为保留的袜子表面，材质 0、1 才进入脱下的鞋。夏妮原始 `l_01_wa__shani` 也保留。统一模型中的鞋与裤腿按完整表面连接区域分类，避免按高度把裤腿切进鞋里。

每侧腿脚、连续丝袜、可脱鞋分别使用独立 Mesh 资源和独立 SkinnedMeshRenderer，并通过 CharacterRig 的 anatomicalLegs、hosiery、leftShoe/rightShoe 显式关联。除夏妮使用专属原版袜面外，连续袜层复制游戏腿脚的原始三角面、顶点和骨骼权重，覆盖脚趾、脚背、脚底至服装遮挡区；它是项目服装适配，并不是从游戏提取到的每位人物专用完整丝袜。袜层为不透明表面，里面的原始皮肤渲染器保留但关闭，避免重合面闪烁。脱鞋只关闭鞋子，腿脚和袜层始终保留。

穿靴时袜层使用 Stocking Coverage 材质遮挡鞋内表面，避免通用游戏脚趾露出较窄的角色靴壳。鞋子转为手持物后，遮挡跟随靴子直到脚完全抽出，再取消对应袜层遮挡。袜面网格本身没有删除三角面。

叶奈法不再加载旧版 DLC_Stocking 圆筒形补袜网格，连续袜面使用无底色贴图、无法线花纹贴图的中性纯黑材质。其他角色原始袜子和裤腿表面仍保留。

爱丽丝和女公爵的长裙先由空闲手抓住前裙摆并提起，露出鞋，再由另一只手抓鞋口脱鞋。提裙范围覆盖工作腿一侧的前裙及侧片，避免窄提裙区域仍然遮住靴口。靴筒完全离开脚后放回裙摆，再俯身放鞋；避免一直保持裙布在膝上，俯身时布片顶住胸口。爱丽丝的原始通用腿网格延伸至 0.90m 的服装重叠区，补齐提裙后可见的大腿，仍使用游戏原始三角面。

短靴的躯干前倾补偿随伸手程度渐进进入和退出，肘部使用稳定的外侧约束方向，避免伸手/收手阈值导致骨骼突然转动。原始布料的自由度权重用于项目内的动态求解，裙摆有坐姿及提起姿态适配。

鞋型按鞋网格实际高度分为鞋（不超过 0.16m）、短靴（0.16–0.30m）和长靴（超过 0.30m）。短靴抓靴口，抽出距离为 0.22m，不采用长靴绷脚；长靴沿靴筒方向抽出 0.50m 并配合脚踝伸展。长裙角色保持提裙流程，具体抽鞋动作仍由鞋型决定。

编辑器菜单 Homecoming/审阅独立腿袜鞋 会输出 Artifacts/FootwearAudit/inventory.csv，检查独立网格、适配袜面与源腿脚一致、夏妮原版白袜来源、骨架一致、脱鞋后袜层保持显示、黑袜无花纹，以及先提裙再抓鞋。

连续运行复查可在独立验证项目中以 batchmode 执行 Homecoming.Editor.HomecomingContinuousReview.FullReview。它进入 Play Mode，对七个角色各执行 961 个 30Hz 时间步，调用实际场景 Update，检查手持鞋接触、袜层保留、重播和骨骼连续性，并保存关键帧。该批处理方法结束后会关闭运行它的验证编辑器。

夏妮现使用游戏原版白袜 `dlc/ep1/data/characters/models/secondary_npc/shani/model/l_03_wa__shani.w2mesh`，来自婚礼脱鞋外观。该资源包含完整封闭袜脚、原始白色袜面、膝部红系带；保留原始 UV、法线、三角面与骨骼权重。完整转换源保存在 `Assets/ThirdParty/WitcherShaniOriginalSocks/Prepared`，当前裤装下只选择原始三角面至 0.50m 的遮挡重叠区域。它替代了此前将通用女性裸足网格染白的袜层，原始通用腿脚仅作为独立关闭的解剖参考保留。

白袜使用原版 `l_02_wa__shani_d01`、`l_02_wa__shani_n01`、`detailmap_shani_socks` 贴图，并采用资源中的织物平铺参数 100/99 与 DetailPower 0.30。Unity URP 材质适配原始纹理输入，不声称完整复现游戏材质图和光照。脱靴不移除白袜，导入和重新构建均保留该来源。原始文件 SHA-256 记录于 `Prepared/source-provenance.json`。

特莉丝角色槽现替换为官方免费 DLC6 外观 `triss_dlc`，入口资源为 `dlc/dlc6/data/characters/npc_entities/main_npc/triss_dlc.w2ent`。服装和靴子来自 `body_01_wa__triss_dlc`；裙摆、袖子和配饰保留原始 REDcloth 自由度。袖子独立跟随手臂，裙摆单独适配坐姿与提裙；转换时将缓存布料从原姿态重绑定到统一骨架，避免袖子错位。这个外观露出裸腿，连续下腿/脚适配使用原始通用女性皮肤贴图，原版身体中的遮挡下层不重复渲染，以避免与旧黑袜层重合。

所有可选角色及场景均移除通勤提包、放置的提包、家居拖鞋和待换拖鞋。导入器不再生成这些配件；运行时兼容清理旧预制体中的遗留配件。取消走路时右臂持包限制及放包/穿拖鞋逻辑，脱下原鞋后直接以袜脚或裸足站起。鞋袜分离、提裙抓鞋和短/长靴区分仍保留。

夏妮的原版白袜遮挡直接使用 `CharacterRig.hosiery` 引用，不再依赖旧渲染器名称。靴子转移到手上后，遮挡继续跟随鞋子直至抽脚完成：长靴从抓鞋开始后 3.05 秒清除，短靴/普通鞋为 2.8 秒，避免脚尚在鞋内就提前露出袜面。

手部动作使用导入人物的原始手掌与手指骨架校准掌向和弯曲轴，不新增手部网格。行走采用减弱的自然摆臂；坐下后手掌落在按实际衣物表面测量的腿部位置。脱鞋手的手指先闭合在鞋口，再抽鞋、缓慢放到地面、松指后收手；空闲手扶工作腿膝部，长裙角色则先以拇指和食指捏住裙摆，提裙后保持布料接触，放回裙摆并松指后收手。手肘平面和掌向恢复限制旋转速度，腕部限制反折角度；旋转修正时保留接触点，避免鞋和裙摆脱离手。

手部专项检查可执行 `Homecoming.Editor.HandMovementReview.FullReview`，先检查七个角色完整时间线的手掌、手指、手肘连续性、腕部弯折、持鞋接触与真实捏布间隙，再执行现有 Play Mode、衣物动态和鞋袜回归。`Capture` 保存动作关键帧至 `Artifacts/HandMovementReview`；批处理完整检查在独立验证项目中运行，结束后关闭该验证编辑器。
